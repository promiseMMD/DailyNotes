# DailyNotes 0.1.0 预览版

基于 Moodiary 固定版本及原魔改代码，按 V3.92 开发规范持续迭代。独立应用包名 `io.github.promisemmd.dailynotes`，Android 9 及以上、arm64。此为功能与布局预览，尚未完成规范的全部功能和真机验收。

## 本轮实现

- 日记/待办/笔记/助手四个主菜单，沿用 Moodiary 胶囊导航和右侧独立圆形操作按钮。
- 新增当天/分组待办、月历选日、任务编辑及完成操作。
- 新增笔记自动保存、文件夹、标签、知识主题层级及原笔记引用；支持软删除和恢复。
- 抽屉菜单、我的数据概览、分项字数、只读数据库检查。
- 长期记录追加全屏编辑、返回保留草稿、提交请求持久化以防未知结果重复追加。
- 日记普通列表的独立排序面板。原日记、长期记录、媒体和设置能力保留为基线。
- AI 预览限手动输入的普通对话，禁用未完成授权审查的应用数据工具、隐式上下文和附件发送。

## 请特别注意

**新笔记、待办、知识主题目前仅本机保存，不参与现有 WebDAV 同步或原版导出备份。** 持久化事件队列已建立，尚无新模块的远端发送/确认实现。页面会明确提示。请先用测试内容试用，不把预览版当作唯一资料存储。

尚未完成：规范中的完整增量同步/冲突管理、跨模块备份及官方数据导入、复杂回收站管理、完整版本历史和附件工作流、重复任务/通知、AI 知识检索与整理审核、全部页面视觉核对，以及真机验收。长期记录月季年阅读仍需对照规范继续补齐。

预览 APK 使用测试签名。工作流每次新建的测试密钥不同，只有证书相同才可覆盖安装；安装前应比较签名记录。正式签名配置尚未完成。不要为安装不同签名的 APK 卸载有重要数据的旧预览版。

源码及 AGPL-3.0 许可证随仓库提供，保留 Moodiary 原作者署名。构建产物附源提交、SHA-256、包信息及签名报告；这些不等于真机运行或数据安全验收通过。

## AppFlowy 编辑器体验

新建日记、新建笔记和长期记录追加共用 AppFlowy 风格正文画布、移动工具栏和排版面板。已有记录默认只读，解锁后可编辑。日记和笔记自动保存到本机；长期追加先保存草稿，只有主动提交才成为正式记录。常见的旧纯文本笔记和简单格式旧日记可进入新画布；尚不能安全转换的复杂历史日记继续使用原读取流程。

笔记页面右上角的「编辑器体验」仍是临时试用画布，退出后内容清除。要保存真实笔记，请使用笔记页下方的新建按钮。Aa 主面板按 DN-205 默认显示为底部半屏，可拖动顶部展开或收起；这与 AppFlowy 标签源码中的键盘区 Aa 不同。标题按 H1、H2、H3、正文排列并显示当前状态；链接与行内代码共用一组入口，可在单区块光标处插入链接或修改选中文字及地址，长按或点下拉可设置行内代码。颜色和高亮合并在底部弹层，字体选择使用独立页面；子界面完成或返回后先回到 Aa。系统返回关闭 Aa 时不主动弹键盘，点击 Aa「完成」时才按有效的原上下文请求恢复先前键盘。跨区块链接、色板与字体资源及视觉布局尚未完全对齐；媒体附件、表格、中文输入法和 Android 真机体验仍需继续开发或验证，目前不能视为与 AppFlowy 完整应用一致。

日记和长期追加的完整 AppFlowy 文档保存在版本化数据中，列表文字是单独生成的摘要。旧局域网编辑器不能修改新格式的内容；新格式的手动备份与恢复仍需验证。文件导出未完全适配。使用 AppFlowy Editor 6.2.0 源码副本及其许可证，针对 Flutter 和 file_picker API 做最小兼容修改。

## 本地开发中的富文本和安全功能

新建笔记可进入 AppFlowy 富文本编辑器，并将版本化文档及本地同步事件写入事务；已有富文本默认只读。保存失败时支持重试、复制内容、风险确认及部分加密应急导出。普通笔记与富文本笔记的应急导出不包含附件，不能代替完整备份。新增笔记、待办及知识主题仍未接入 WebDAV 同步或完整备份。自动 WebDAV 已禁用，用户手动同步及 Android 真机恢复仍需验证。此预览仅供测试，请勿作为重要资料的唯一存储。

V3.67 的历史保留规则已用于保护当前长期记录的历史版本：数据库迁移或重置遇到这些版本时会停止清空。完整历史管理、正式 Snapshot 登记及其受授权删除流程仍未实现。

V3.92 的手机工具栏仍在分阶段调整：日记、笔记及长期追加的原生文档编辑器已提供顶部撤销/重做，笔记和长期追加提供文档级操作菜单；文字选区浮动菜单可在键盘显示或收起时出现，并为键盘上方工具栏保留空间。各入口、选区手柄与中文输入法仍需 Android 真机验证。表格结构和删除安全规则尚未实现，因此未开放表格插入入口。

正文「+」可插入普通折叠列表及 1～3 级折叠标题。无子内容的段落或标题开头输入 `> `，也可以转换为折叠列表或对应级别的折叠标题；带子内容或存在歧义属性的区块暂不自动转换。展开时可添加子内容；单区块回车保留原有子树并可撤销。折叠区块处于收起状态时，在标题开头回车会在上方插入段落并保留标题光标。光标在折叠标题开头时按退格，可移除标题级别并保留折叠区块及子内容；其他退格情况尚未完整对照。跨折叠区块选区换行暂不支持，操作被阻止时会尝试恢复输入连接中的原选区。阅读锁定时也可展开和折叠；为保护隐藏选区，选区位于子内容中时请先移出选区。折叠状态是当前页面的显示状态，不改写正文，重新打开后使用文档原有状态。包含新折叠区块的文档需要新版 APK，旧版可能无法打开；中文输入法、视觉和真机交互仍需验证。

选区浮动菜单增加「全选」；剪切和粘贴仍待完成。按规范跟踪的编辑器验收点和其他模块状态见仓库中的 `docs/DEVELOPMENT_PROGRESS.md`。

本地后续改动：已有记录的只读选区可复制和全选，不显示修改格式的操作；只读选择不会主动弹出键盘，外接键盘的写入和撤销类快捷键受锁定保护。尚需 Android 真机验证。

本地还加入了选区手柄拖动期间隐藏浮动菜单、锁定状态切换时重新计算菜单布局的保护。剪贴板安全内核支持单区块纯文本操作，以及普通顶层段落的多行粘贴，目前未接入用户界面；富文本和跨区块仍需完成。

键盘上方工具栏会根据可用宽度将快捷操作收纳到「更多」，不通过横向滚动寻找；在 160 逻辑像素宽度下可从「更多」收起键盘。菜单打开后改变窗口宽度仍可执行先前显示的操作；文字选区浮动菜单在窄屏时分行，保留各项操作并避开选区与底部工具栏。当前已自动化验证 160、192、240、320、430 逻辑像素宽度及选区保护，更窄宽度、Android 真机、无障碍字号和其他区块上下文仍待验证。

日记、笔记和长期追加可从右上角打开标题目录，按层级展开或折叠并搜索；搜索显示匹配标题及其上级路径，一键清除后恢复原目录折叠状态。目录默认包含折叠标题，普通折叠列表可手动开启显示；跳转到隐藏标题会先展开正文中的折叠祖先。目录复用已提取的标题，正文结构变化时重新建立列表；真实长文性能仍待实机验证。目录跳转后可以重新打开目录，点击返回图标回到跳转前可识别的阅读位置；该临时返回点仅在当前页面会话内保留。已有笔记、日记和长期记录会另行记录本机阅读位置，同一会话中正文确认保存、原区块仍可识别且位置元数据成功写入时会跟随变更；确认失效时不自动猜测，主动滚动可记录新位置。正文与位置元数据不是同一事务，写入失败时不能保证跨重启跟随。跨会话或外部改动后的稳定区块身份、独立编辑光标和 Android 实机仍待完成或验证。目录开合不会主动抢走正文焦点；搜索后只在文档、选区和锁定等上下文仍有效时恢复逻辑选区，不强行弹出键盘。搜索后的输入连接仍需验证。阅读锁定时点击链接仍可打开，长按不会弹出链接编辑框或键盘。三类记录的顶部文档菜单与底部正文菜单分离；笔记在阅读锁定时不能从文档菜单删除或归档；笔记归档已接入，历史版本尚未接入。

已有笔记、日记和长期记录可在右上角文档菜单的「书签」中添加、命名、跳转和删除同篇书签，删除后可在当前窗口撤销。同一编辑会话中，正文成功保存且原区块仍可识别时，书签会跟随更新；失效书签会保留，用户可滚动到新位置后在书签菜单中确认重新绑定。书签仅在本机保存，尚不参与备份或同步；跨会话或外部修改后可能暂时失效，持久区块身份和跨文档书签仍待实现。新版可读取旧版书签；升级后的书签格式不兼容旧版 APK。

输入法状态现在区分组合中、排队、正在处理和无法确定的情况，多个编辑器实例不会通过共用的防抖标识互相取消输入；组合过程和光标前文本的替换不会误触发结构快捷操作。异步剪贴板操作可据状态变化取消过期操作。输入法连接关闭或重新关联时，待处理文字如何可靠保留仍需解决，页面/焦点有效期和 Android 中文输入法真机也未完成验证，因此剪切和粘贴仍未开放。

笔记解锁后可从文档菜单归档或取消归档，归档后仍停留在当前笔记。左侧抽屉的「归档管理」可按原文件夹或知识主题查找和打开已归档笔记。归档状态目前仅保存在本机，尚未纳入同步或备份；日记和长期记录归档尚未开放，Android 真机体验待验。V3.92 的附件导入任务、后台处理和全局状态入口尚未实现。

文件夹深层路径清单支持按需搜索整个文件夹树，显示完整路径并提供一键清除；没有精确匹配时可展开最多三项基础错字建议。拼音、专业别名、匹配阈值和 Android 真机体验尚待完成。

编辑器插入标题等区块时，带额外属性或嵌套内容的空段落会被保留；分隔线会复用可编辑空段落，插入可独立撤销。复杂区块、输入法及实机体验仍需验证。

笔记的标题、文件夹和标签随正文共同滚动；日记及长期追加的业务头部也位于正文滚动区域。三类入口已有自动化滚动测试，Android 真机键盘与手势仍待验收。

笔记移动前显示完整文件夹路径并要求确认；目标或祖先路径变化、读取失败时不发起移动，保存事务内也会校验目标及祖先修订。批量和跨设备冲突处理尚未完成。

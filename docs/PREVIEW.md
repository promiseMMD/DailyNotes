# DailyNotes 0.1.0 预览版

基于 Moodiary 固定版本及原魔改代码，按 V3.92 开发规范持续迭代。独立应用包名 `io.github.promisemmd.dailynotes`，Android 9 及以上、arm64。此为功能与布局预览，尚未完成规范的全部功能和真机验收。

## 本轮实现

- 日记/待办/笔记/助手四个主菜单，沿用 Moodiary 胶囊导航和右侧独立圆形操作按钮。
- 新增当天/分组待办、月历选日、任务编辑及完成操作。
- 新增笔记自动保存、文件夹、标签、知识主题层级及原笔记引用；支持软删除和恢复。
- 抽屉菜单、我的数据概览、分项字数、只读数据库检查。
- 长期记录追加全屏编辑、返回保留草稿、提交请求持久化以防未知结果重复追加。
- 日记普通列表的独立排序面板。原日记、长期记录、媒体和设置能力保留为基线。
- AI 预览限手动输入的普通对话，禁用未完成授权审查的应用数据工具、隐式上下文和附件发送。

## 请特别注意

**新笔记、待办、知识主题目前仅本机保存，不参与现有 WebDAV 同步或原版导出备份。** 持久化事件队列已建立，尚无新模块的远端发送/确认实现。页面会明确提示。请先用测试内容试用，不把预览版当作唯一资料存储。

尚未完成：规范中的完整增量同步/冲突管理、跨模块备份及官方数据导入、复杂回收站管理、完整版本历史和附件工作流、重复任务/通知、AI 知识检索与整理审核、全部页面视觉核对，以及真机验收。长期记录月季年阅读仍需对照规范继续补齐。

预览 APK 使用测试签名。工作流每次新建的测试密钥不同，只有证书相同才可覆盖安装；安装前应比较签名记录。正式签名配置尚未完成。不要为安装不同签名的 APK 卸载有重要数据的旧预览版。

源码及 AGPL-3.0 许可证随仓库提供，保留 Moodiary 原作者署名。构建产物附源提交、SHA-256、包信息及签名报告；这些不等于真机运行或数据安全验收通过。

## AppFlowy 编辑器体验

新建日记、新建笔记和长期记录追加共用 AppFlowy 风格正文画布、移动工具栏和排版面板。已有记录默认只读，解锁后可编辑。日记和笔记自动保存到本机；长期追加先保存草稿，只有主动提交才成为正式记录。常见的旧纯文本笔记和简单格式旧日记可进入新画布；尚不能安全转换的复杂历史日记继续使用原读取流程。

笔记页面右上角的「编辑器体验」仍是临时试用画布，退出后内容清除。要保存真实笔记，请使用笔记页下方的新建按钮。Aa 面板支持系统字体和已导入字体、显示当前字体，可对同级多段文字进行块格式转换；选中文字可添加或移除链接。正文工具栏的部分操作收纳到“更多”，不再通过横向滑动查找。面板遮挡选区时按需调整滚动。媒体附件、表格以及中文输入法和 Android 真机体验仍需继续开发或验证，目前不能视为与 AppFlowy 完整应用一致。

日记和长期追加的完整 AppFlowy 文档保存在版本化数据中，列表文字是单独生成的摘要。旧局域网编辑器不能修改新格式的内容；新格式的手动备份与恢复仍需验证。文件导出未完全适配。使用 AppFlowy Editor 6.2.0 源码副本及其许可证，针对 Flutter 和 file_picker API 做最小兼容修改。

## 本地开发中的富文本和安全功能

新建笔记可进入 AppFlowy 富文本编辑器，并将版本化文档及本地同步事件写入事务；已有富文本默认只读。保存失败时支持重试、复制内容、风险确认及部分加密应急导出。普通笔记与富文本笔记的应急导出不包含附件，不能代替完整备份。新增笔记、待办及知识主题仍未接入 WebDAV 同步或完整备份。自动 WebDAV 已禁用，用户手动同步及 Android 真机恢复仍需验证。此预览仅供测试，请勿作为重要资料的唯一存储。

V3.67 的历史保留规则已用于保护当前长期记录的历史版本：数据库迁移或重置遇到这些版本时会停止清空。完整历史管理、正式 Snapshot 登记及其受授权删除流程仍未实现。

V3.92 的手机工具栏仍在分阶段调整：日记、笔记及长期追加的原生文档编辑器已提供顶部撤销/重做，笔记和长期追加提供文档级操作菜单；键盘收起时提供独立的文字选区浮动菜单。各入口、选区手柄与中文输入法仍需 Android 真机验证。表格结构和删除安全规则尚未实现，因此未开放表格插入入口。

笔记归档目前只有本地数据基础，尚未开放归档入口与归档管理界面；归档同步、备份恢复和日记/长期记录归档均未完成。V3.92 的附件导入任务、后台处理和全局状态入口尚未实现。

## V3.72 新增确认项（DN-258）

- 用户同意普通表格最小结构为 1 行 × 1 列，不允许删除唯一剩余行或列使结构变成 0 行/0 列。
- 1×N 表格可以删除其他列，但不能删除唯一剩余列；N×1 表格可以删除其他行，但不能删除唯一剩余行。达到 1×1 后仍保留表格，可继续编辑、清空单元格或重新插入行列。
- 若要移除表格本身，必须使用 DN-257 整表删除并二次确认；不得通过删除最后一行/列绕过确认。
- 最小结构限制必须在共享文档操作/领域规则层落实，覆盖 Android、PC、Undo/Redo、批量操作及远程 API，不得只依赖 UI 隐藏按钮。
- 本条仅为已确认设计规则，不代表代码实现或测试已完成。

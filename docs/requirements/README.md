- **最新设计讨论参考**：使用 V3.12；它完整包含 V2.51（DN-001～DN-177）并增量记录已确认的 DailyNotes 3.0 决策 DN-204～DN-220。
- **历史缺口必须保留**：此前聊天提到 V2.52～V2.77、DN-178～DN-203，但当前仓库缺少可逐条核验的规范原文；相关决策有摘要而非精确编号。**禁止将缺口视为已完成核对**，也不得自行编造或覆盖。
- **决策状态不可混用**：已确认、待讨论、实现候选、已编码、已测试必须分开标注。可交互概念图只是行为示意。
- **同步节奏**：用户确认的设计决定先在对话决策台账中记录；累计约 5～8 项、模块设计完成、发生重大架构决策、进入编码前主动提醒。仅用户批准后集中同步 GitHub，并读回校验内容、编号和提交 SHA。
- **设计阶段**：当前不因规范同步而修改 App 业务代码、CI 或 APK；真实数据持久化/应急包加密/恢复能力不得仅凭设计文本宣称已实现。

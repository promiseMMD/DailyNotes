## 修改范围与风险

仅新增 Flutter UI 预览、Widget 测试和 CI，没有写入手机个人数据、网络调用或修改既有存储。Flutter 是当前**可替换的 UI 实现尝试**，不表示 Flutter/Rust 分界、SQLite Schema、设备身份、包名、加密或同步细节已经获最终批准。Android 预览项目由 CI 的 `flutter create` 临时生成，不作为稳定签名的正式 APK。
